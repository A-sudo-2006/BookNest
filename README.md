# 📚 BookNest

BookNest is a web-based online bookstore designed to provide a simple, attractive, and user-friendly platform for browsing books, managing a shopping cart, and placing orders.

## ✨ Features

- 📖 Browse available books
- 🛒 Add books to cart
- ➕ Update book quantities
- 🗑️ Remove books from cart
- 💳 Checkout and place orders
- ✅ Order confirmation page
- 🗄️ MySQL database integration
- 🎨 Responsive and aesthetic user interface
- ⚡ PHP-based backend

## 🛠️ Technologies Used

- **HTML** — Website structure
- **CSS** — Styling and responsive design
- **PHP** — Backend functionality
- **MySQL** — Database management
- **XAMPP** — Local development server
- **Git & GitHub** — Version control

## 🚀 How to Run Locally

### 1. Install XAMPP

Install XAMPP with Apache and MySQL.

### 2. Place the project

Put the BookNest folder inside:

```text
C:\xampp\htdocs\BookNest
```

### 3. Start XAMPP

Start:

- Apache
- MySQL

### 4. Set up the database

Open phpMyAdmin:

```text
http://localhost/phpmyadmin
```

Create or import the BookNest database and make sure the database settings in `db.php` match your MySQL configuration.

### 5. Run BookNest

Open:

```text
http://localhost/BookNest/
```
